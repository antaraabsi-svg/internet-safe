# إنترنت آمن، جيل واعٍ
برنامج تحسيسي تفاعلي لاستخدام سليم وآمن للإنترنت ومواقع التواصل الاجتماعي — ديوان قطاع الشباب والرياضة.

## الملفات
- `index.html` — البرنامج كاملاً (صفحة واحدة تعمل دون خادم).
- `intro.mp4` — فيديو المدخل، يجب أن يبقى بجوار `index.html` وبهذا الاسم.

## التشغيل
افتح الرابط المنشور عبر GitHub Pages، أو افتح `index.html` مباشرة في المتصفح.
لا يجمع البرنامج أي بيانات؛ تبقى النتائج في جهاز المستخدم.
